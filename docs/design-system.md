# Design system

The public experience follows a restrained technical retail language: Inter for interface text, JetBrains Mono for metadata, deep indigo actions, slate tonal surfaces, compact borders, and minimal shadow. Content is capped at 1280 px with 24 px desktop and 16 px mobile gutters. Spacing follows an 8 px rhythm and radii stay between 6–8 px.

Light, dark, and system themes share semantic CSS tokens for backgrounds, surfaces, text, borders, focus, and status. Controls retain a 44 px minimum touch target, visible keyboard focus, semantic labels, and native dialog behavior. Motion is limited to loading feedback and is disabled by `prefers-reduced-motion`.

Product imagery uses fixed aspect ratios, lazy decoding, a reserved loading surface, and a localized failure fallback to avoid layout shift. The source references are inspiration only; fictional testimonials, checkout, production performance claims, and unrelated brand assets are intentionally excluded.
