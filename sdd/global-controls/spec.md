# Global controls requirements

## Goal

Align the storefront's theme and language utilities with the canonical portfolio header while preserving cart and retail navigation.

## Requirements

- Replace the theme select with the canonical compact disclosure and three real buttons.
- Replace the alternate-locale abbreviation with the canonical `EN / ES` switch.
- Keep theme, language, and cart utilities in that order after project navigation.
- Preserve theme persistence, localized labels, base-path-safe locale routes, and mobile access.

## Acceptance criteria

- Browser tests cover theme selection, locale navigation, accessibility, and narrow layouts.
- Existing cart, catalog, and recommendation behavior remains unchanged.
