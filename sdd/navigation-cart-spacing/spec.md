# Navigation and cart spacing

## Requirements

- Show Portfolio as the final project-menu destination in both languages.
- Keep the cart visible as the principal product-specific header action.
- Separate the cart and menu from global settings without creating mobile overflow.
- Remove duplicate Portfolio links from the header and footer.

## Acceptance criteria

- Theme and language form the global-control group.
- A subtle divider and consistent gap distinguish cart and menu actions.
- The cart drawer and project navigation remain usable at desktop and 390 px widths.
- Browser accessibility and interaction tests pass.
