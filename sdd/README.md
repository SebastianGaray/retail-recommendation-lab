# Spec-driven development

This directory records the requirements, design, and completed tasks for Retail Recommendation Lab.
The specifications define the visitor experience, artifact contracts, recommendation behavior, and
delivery evidence that must remain aligned.

- `requirements.md`: functional, integrity, artifact, and delivery requirements.
- `design.md`: offline/online boundary, ranking architecture, and verification strategy.
- `tasks.md`: completed implementation and validation tasks.

A change is complete only when its public behavior, generated artifacts, tests, and documentation
agree with the relevant specification.
